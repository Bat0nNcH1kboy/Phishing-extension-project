# Расширение веб-браузера для обнаружения фишинговых сайтов

Проект представляет собой расширение для браузера Chrome/Chromium, предназначенное для проверки URL-адресов на наличие признаков фишинга. Расширение работает совместно с локальным backend-сервером на Flask. Пользователь может проверить текущую открытую вкладку или вручную вставить ссылку в окно расширения.

Основная идея проекта — объединить несколько подходов к анализу URL:

- проверку адреса по локальной базе;
- извлечение признаков из URL;
- машинное обучение;
- эвристическую оценку;
- дополнительную DNS-проверку домена.

Проект ориентирован на практическое применение в качестве инструмента предварительной проверки ссылок и может использоваться для демонстрации подходов к обнаружению подозрительных веб-адресов.

## Состав проекта

В проект входят две основные части:

```text
backend/       серверная часть на Flask
extension/     расширение для браузера Chrome/Chromium
```

Также в проекте есть вспомогательные файлы и папки:

```text
docs/          дополнительные материалы
scripts/       скрипты для проверки проекта
.github/       настройки автоматической проверки на GitHub
```

## Возможности

В проекте реализованы следующие функции:

- проверка текущего URL из активной вкладки браузера;
- ручной ввод URL в popup-окне расширения;
- отправка ссылки на локальный Flask backend;
- анализ URL по набору признаков;
- использование обученной модели машинного обучения;
- проверка домена по локальной базе вердиктов;
- DNS-проверка существования домена;
- отображение результата проверки в интерфейсе расширения.

Результат проверки включает общий вердикт, уровень риска, вероятность фишинга и краткое объяснение причин. Это позволяет пользователю не только получить итоговый результат, но и понять, какие признаки повлияли на оценку URL.

## Технические особенности

В проекте используется модель `TexturedUrlClassifier`, которая объединяет признаки, извлечённые из URL, и дополнительные URL-текстуры. Под URL-текстурами понимаются символьные особенности адреса: сочетания букв и цифр, подозрительные токены, длинные случайные фрагменты, наличие слов вроде login, verify, account и другие признаки.

Также реализован ручной ввод URL в popup-окне расширения. Это позволяет проверять не только текущую вкладку браузера, но и ссылку, скопированную из письма, сообщения или другого источника.

В репозитории настроен CI workflow для автоматической проверки проекта на GitHub. Для локальной проверки используется скрипт `scripts/check_project.py`.

Для подключения расширения в Chrome необходимо открыть `chrome://extensions`, включить режим разработчика и выбрать пункт «Загрузить распакованное расширение».

## Backend

Backend реализован на Flask и предоставляет API для проверки URL.

Основной endpoint:

```text
POST /api/check
```

Пример запроса:

```bash
curl -X POST http://127.0.0.1:5001/api/check \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com"}'
```

Также есть endpoint для проверки состояния сервера:

```text
GET /health
```

Backend принимает URL, выполняет его обработку, извлекает признаки, обращается к локальной базе вердиктов, использует модель машинного обучения и возвращает результат проверки в формате JSON.

## Расширение для браузера

Расширение работает через popup-окно. В нём можно проверить текущую открытую вкладку или вставить URL вручную.

Для корректной работы расширения backend должен быть запущен локально.

## Запуск backend

Перейти в папку backend:

```bash
cd backend
```

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Активировать окружение.

Для Windows:

```bash
.venv\Scripts\activate
```

Для macOS/Linux:

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить сервер:

```bash
python app.py
```

После запуска сервер должен быть доступен по адресу:

```text
http://127.0.0.1:5001
```

## Подключение расширения в Chrome

1. Открыть в браузере страницу:

```text
chrome://extensions
```

2. Включить режим разработчика.

3. Нажать «Загрузить распакованное расширение».

4. Выбрать папку:

```text
extension
```

5. Запустить backend.

6. Открыть любой сайт или вставить URL вручную в окно расширения.

7. Нажать кнопку проверки.

После этого расширение отправит URL на backend и отобразит результат проверки в интерфейсе.

## Обучение модели

В проекте уже есть сохранённая модель, поэтому для обычного запуска переобучение не требуется.

При необходимости модель можно обучить заново:

```bash
cd backend
python model_train.py
```

Датасет находится в файле:

```text
backend/data/dataset.csv
```

Он используется для обучения и проверки работы алгоритма.

## Генерация данных

В проекте есть скрипт генерации данных:

```bash
cd backend
python data_generator.py --size 100000
```

В текущей конфигурации для демонстрации работы проекта используется набор данных и локальная база вердиктов объёмом до 100 000 записей. Это позволяет проверить работу алгоритма на большом количестве URL и показать взаимодействие базы, признаков URL и модели машинного обучения.

После генерации данных можно заново обучить модель:

```bash
python model_train.py
```

Локальная база вердиктов используется для ускорения проверки известных доменов и демонстрации работы репутационного подхода.

## Примеры URL для проверки

Безопасный пример:

```text
https://example.com
```

Пример подозрительного URL:

```text
https://secure-login-example.bad/account
```

Пример URL с имитацией известного бренда:

```text
https://paypa1-login-secure.example.bad/account?token=ABCDEF1234567890XYZ
```

Пример с IP-адресом вместо домена:

```text
http://192.168.0.1/secure/login/verify/account
```

Некорректный URL:

```text
https://.
```

## Особенности реализации

В проекте используется комбинированный подход к проверке URL. Итоговый результат формируется на основе нескольких источников:

- локальной базы вердиктов;
- признаков, извлечённых из структуры URL;
- модели машинного обучения;
- эвристических правил;
- DNS-проверки домена.

Такой подход позволяет учитывать как заранее известные адреса, так и новые URL, которых нет в локальной базе.
